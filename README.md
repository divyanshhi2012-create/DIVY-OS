# 🌟 About DivyOS

**DivyOS** is a modern desktop operating system interface developed using **Python** and **Tkinter**.

The goal of DivyOS is to provide a clean, beautiful, and lightweight desktop experience inspired by modern operating systems such as HyperOS and Windows while remaining completely open source.

This project is created and maintained by **Divyansh Singh**.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/divyanshhi2012-create/DIVY-OS.git
```

Go to the project

```bash
cd DIVY-OS
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run DivyOS

```bash
python main.py
```
